## 摘要
本章介绍了用于微调金融预测器的三种主要强化学习算法。我们提出了一套清晰的实施方案，用于将强化学习任务的损失反向传播到使用监督学习训练的模型中，并对比了微调前后的性能。研究发现，微调后模型性能有所提升，并展现出迁移学习特性，这表明了微调的益处。我们还重点阐述了调优过程和实证结果，以供从业者在未来的实施中参考。

## Abstract
This chapter presents three major reinforcement learning algorithms used for fine-tuning financial forecasters. We propose a clear implementation plan for backpropagating the loss of a reinforcement learning task to a model trained using supervised learning, and compare the performance before and after the fine-tuning. We find an increase in performance after fine-tuning, and transfer learning properties to the models, indicating the benefits of fine-tuning. We also highlight the tuning process and empirical results for future implementation by practitioners.

### 2. 方法论
*   **核心思想**：使用预训练的Transformer模型作为骨干网络（Backbone），将其接入强化学习框架中，通过环境交互产生的奖励信号来更新模型权重。

    *   **两种范式**：
        1.  **潜变量范式（Latent Paradigm）**：骨干网络输出特征，由额外的动作网络生成预测。
        2.  **执行器范式（Actor Paradigm）**：骨干网络直接作为执行器输出预测。实验证明执行器范式效果更好。
    *   **奖励函数**：设计为 $r_t = 2 \times e^{(-MSE(a_t, y_t))} - 1$，将奖励值约束在 $[-1, 1]$ 之间，MSE越小奖励越高。

### 6. 主要结论与发现
*   **GRPO表现最优**：在微调任务中，GRPO由于不需要评论家网络（Critic Network），降低了架构复杂度，避免了与骨干网络之间的梯度干扰，效果优于PPO和CMAPPO。
*   **微调显著提升性能**：经过RL微调的模型在MSE和MAE指标上大多优于原始监督学习模型。
*   **迁移学习能力**：模型展现出强大的跨领域适应性，例如在技术板块预训练的模型，通过RL微调后在工业板块表现优异。
*   **层冻结的必要性**：冻结约50%的编码器层通常能获得最佳性能，这有助于保留预训练阶段学到的高层模式。

*   **创新性**：首次将GRPO等前沿LLM对齐算法应用于时间序列预测的微调。
*   **实用性**：提出的“执行器范式”简化了微调流程，方便从业者直接在现有预训练模型上实施。
*   **成本效益**：相比于重新训练大模型，RL微调提供了一种低成本、高效率的性能提升手段。

*   **输入限制**：受限于预训练骨干网络，模型仍使用固定大小的输入向量，难以处理变长序列。
