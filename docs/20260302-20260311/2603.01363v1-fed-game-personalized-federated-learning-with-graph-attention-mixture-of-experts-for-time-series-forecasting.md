## 摘要
基于图的联邦学习（FL）在分布式时间序列预测中展现出巨大潜力。然而，现有方法依赖于静态拓扑结构，且难以应对客户端的异构性。我们提出了 Fed-GAME，这是一个将个性化聚合建模为在可学习动态隐式图上进行消息传递的框架。其核心是一种基于解耦参数差分的更新协议，客户端传输其微调后的私有模型与共享全局模型之间的参数差分。在服务器端，这些差分被分解为两个流：（1）用于更新全局模型以达成共识的平均差分；（2）输入到新型图注意力混合专家（GAME）聚合器中以实现细粒度个性化的选择性差分。在该聚合器中，共享专家提供评分信号，而个性化门控自适应地对选择性更新进行加权，以支持个性化聚合。在两个真实世界的电动汽车充电数据集上的实验表明，Fed-GAME 优于最先进的个性化联邦学习基准方法。

## Abstract
Federated learning (FL) on graphs shows promise for distributed time-series forecasting. Yet, existing methods rely on static topologies and struggle with client heterogeneity. We propose Fed-GAME, a framework that models personalized aggregation as message passing over a learnable dynamic implicit graph. The core is a decoupled parameter difference-based update protocol, where clients transmit parameter differences between their fine-tuned private model and a shared global model. On the server, these differences are decomposed into two streams: (1) averaged difference used to updating the global model for consensus (2) the selective difference fed into a novel Graph Attention Mixture-of-Experts (GAME) aggregator for fine-grained personalization. In this aggregator, shared experts provide scoring signals while personalized gates adaptively weight selective updates to support personalized aggregation. Experiments on two real-world electric vehicle charging datasets demonstrate that Fed-GAME outperforms state-of-the-art personalized FL baselines.

#### 1. 核心问题与整体含义（研究动机和背景）
在分布式时间序列预测（如电动汽车 EV 充电需求预测）中，不同客户端（充电站）往往表现出截然不同的时间模式和季节性，即**数据异构性（Non-IID）**。现有的联邦学习（FL）方法在处理此类问题时面临两大挑战：
*   **客户端图结构不精确**：现有的图联邦学习（FGL）通常依赖预定义的静态拓扑（如地理距离），无法捕捉任务相关的动态关系。
*   **混合更新的聚合效果不佳**：传统方法将全局共识与个性化信号混为一谈，简单的平均聚合会削弱通用知识并掩盖个性化特征。
**Fed-GAME** 的提出旨在通过动态隐式图建模和解耦参数更新，实现更精准的个性化预测。

#### 2. 方法论：核心思想与关键技术
Fed-GAME 的核心是将个性化聚合建模为在**可学习动态隐式图**上的消息传递。
*   **解耦参数差分协议**：客户端不再上传完整模型，而是上传其微调后的私有模型（$M_A$）与共享全局模型（$M_B$）之间的**参数差分**（$\Delta$）。
*   **服务器端双流处理**：
    1.  **全局共识流**：对所有客户端的差分取平均，用于更新全局模型。
    2.  **个性化聚合流**：提取差分中的选择性组件（如最后几层 MLP），输入到 **GAME（Graph Attention Mixture-of-Experts）聚合器**。
*   **GAME 聚合器机制**：
    *   **共享专家（Shared Experts）**：多个线性网络专家评估客户端对之间的相关性，生成评分信号。
    *   **个性化噪声 Top-k 门控**：每个客户端拥有独立的门控，自适应地为专家评分分配权重，生成稀疏的聚合权重。
    *   **动态图注意力**：基于专家和门控生成的权重，在隐式图上进行消息传递，生成个性化更新。
*   **相似度元损失（Meta-loss）**：服务器利用余弦相似度和均方误差构建元损失函数，在不接触客户端原始数据的情况下训练聚合器。
