## 摘要
深度学习推动了时间序列预测的发展，但周期漂移（即周期时序和相位随时间变化）仍然是一个具有挑战性的问题。现有方法主要将这些序列建模在固定的时间网格上，难以适应与相位相关的变化。为解决这一局限，我们提出了 \textbf{POEM}，一种基于二维特殊正交群 $\mathrm{SO}(2)$ 的潜在特征旋转的相位感知预测框架。POEM 通过学习一个相位校正坐标，并对成对的潜在特征应用基于 $\mathrm{SO}(2)$ 的可逆旋转，旨在减少与相位相关的变异性。为了外推这一校正坐标，方向相位增量注意力（DPIA）从相似的时间上下文中检索历史相位增量，并将其整合到未来的相位校正中。实验表明，POEM 取得了有竞争力的性能，同时定性可视化显示，学习到的相位感知变换使潜在轨迹更加规则。

## Abstract
Deep learning has advanced time series forecasting, but periodicity drift, in which cycle timing and phase vary over time, remains a challenging problem. Existing methods predominantly model these sequences on fixed time grids, suffering from a limited ability to accommodate phase-related variation. To address this limitation, we propose \textbf{POEM}, a phase-aware forecasting framework based on latent feature rotation using the special orthogonal group in two dimensions, denoted by $\mathrm{SO}(2)$. POEM aims to reduce the phase-related variability by learning a phase-correction coordinate and applying an invertible $\mathrm{SO}(2)$-based rotation to paired latent features. To extrapolate this correction coordinate, Directional Phase Increment Attention (DPIA) retrieves historical phase increments from similar temporal contexts and integrates them into future phase corrections. Experiments demonstrate that POEM achieves competitive performance, while qualitative visualizations suggest that the learned phase-aware transformation makes latent trajectories more regular.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：时间序列预测在交通、天气、金融、能源等领域至关重要。深度学习方法通过提取复杂的时间依赖关系取得了显著进展，其成功在很大程度上依赖于对周期性规律的识别和外推。
- **核心问题——周期漂移（Periodicity Drift）**：现实世界的时间序列极少以恒定速率和固定相位重复其周期模式。周期会随运行条件变化而拉伸或压缩，重复事件也会提前或延后到达。论文以心脏循环（静息时约1秒，运动时压缩、深度睡眠时延长）和城市交通晚高峰（夏季出现稍晚）为例说明这一现象。作者将这种时变偏差形式化为**非均匀相位推进**：局部存在一个相位速度（决定周期推进快慢）和一个相位偏移（决定周期锚定位置）。
- **现有方法的局限**：
  - **模板类方法**（如 CycleNet、SparseTSF、TimesNet、PDF）：依赖固定周期长度的模板，当周期速率和相位局部变化时灵活性不足。
  - **相位感知方法**（如 AlignTime、PhaseFormer）：通过全局主导周期对齐或离散相位窗口来缓解相位变化，但全局或离散化的对齐机制没有显式地从局部证据中构建逐通道的相位轨迹。
- **整体含义**：论文提出一个名为 **POEM** 的相位感知预测框架，核心思想是**根据估计的相位校正轨迹对成对特征进行旋转，以补偿相位偏移**，从而得到更规则的时间模式，简化后续预测任务。

### 2. 论文提出的方法论

#### 核心思想
- POEM 的关键洞察是：**将相位校正视为一个随时间演化的过程**，通过估计每条通道在每个局部窗口的相位偏移和相位速度，构建连续的相位校正轨迹。然后利用二维特殊正交群 $\mathrm{SO}(2)$ 的旋转操作，将受相位偏移影响的潜特征投影到更规则的周期轨道上，使其更易于预测。
- $\mathrm{SO}(2)$ 旋转具有**可逆性**（$R(\phi)^\top R(\phi) = I$，$R(\phi)^{-1} = R(-\phi)$），因此可以在预测完成后逆旋转以恢复未来的相位变化。

#### 五个核心模块
1. **局部相位校正估计器（LPCE）**
   - **局部动力学编码器**：将每个变量的归一化回看序列划分为 $W$ 个长度为 $\ell$、步长为 $s$ 的重叠窗口，每个窗口经编码器（卷积混合、自注意力、时间聚合）得到表征 $z_{w,c}$。
   - **相位偏移参数化**：$\theta_{w,c} = \pi \cdot \tanh(\text{MLP}_\theta(z_{w,c}))$，约束在 $(-\pi, \pi)$ 区间内，尊重周期状态的 $2\pi$ 周期性。
   - **相位速度参数化**：$\rho_{w,c} = \text{Clip}(\text{MLP}_v(z_{w,c}), [-\gamma, \gamma])$，$v_{w,c} = \exp(\rho_{w,c})$，通过对数预测和指数化确保速度为正（局部固有时钟向前推进）。
   - **全局连续相位积分器**：通过累积速度场得到窗口起始处的累积相位时间 $\tau_{w,c}$；然后将局部相位锚点按速度传播到窗口内每个时间点，经**圆均值**聚合和**时间解卷**得到连续逐通道的相位校正轨迹 $\Phi_c(t)$。

2. **相位引导的 $\mathrm{SO}(2)$ 特征旋转**
   - 先用线性投影、时间卷积、token 混合 MLP 编码归一化观测，得到特征 $S \in \mathbb{R}^{L \times C \times D}$。
   - 将 $D$ 维特征拆分为 $d = D/2$ 对二维特征对，每对施加旋转 $R(-\Phi_c(t))$，以补偿估计的相位偏移，使变换后特征更规则。

3. **相位校正时间预测器**
   - 在相位校正后的特征 $\tilde{S}$ 上，沿回看维度应用轻量 MLP 块（保持变量和特征维度不变），再通过线性投影将时间维度从 $L$ 映射到 $H$，得到未来相位校正特征 $\hat{S}^{pc}$。

4. **方向相位增量注意力（DPIA）**
   - **方向查询与键**：未来时间戳编码作为查询（$q_h$），历史时间戳编码（$j=2,\dots,L$）作为键（$k_j$），经可学习的投影和 $\ell_2$ 归一化后计算余弦相似度。
   - **通道级相位增量作为值**：历史相位增量 $v_j = [\Phi_c(j) - \Phi_c(j-1)]_{c=1}^C$（一阶差分对常数相位偏移不变，直接描述局部相位变化）。
   - **缩放余弦注意力**：注意力权重 $A = \text{Softmax}(\kappa QK^\top)$，其中 $\kappa = \text{Softplus}(\kappa_{raw}) + \epsilon$ 为可学习的正缩放因子。
   - **未来相位积分**：通过 $\delta = AV$ 聚合历史增量，再经累积求和恢复未来相位校正轨迹 $\hat{\Phi}_c(L+h)$。

5. **相位恢复与解码**
   - 对预测的相位校正特征施加反向旋转 $R(\hat{\Phi}_c(L+h))$，恢复未来相位变化。
   - 线性解码器将恢复的特征映射为最终预测 $\hat{Y}$，并反转输入归一化。

### 6. 论文的主要结论与发现

- POEM 在 9 个数据集的平均性能上，于 18 个比较（9 数据集 × MSE/MAE）中 12 个达到最优或次优，为所有模型中最高。
- 与最强基线 PMDformer 相比，POEM 平均 MSE 降低 **11.9%**，在 9 个数据集中 7 个上取得更优表现。
- 消融实验表明：
  - 去除 SO(2) 旋转后所有数据集 MSE 均上升（如 US Birth 从 0.301 升至 0.399），验证了旋转的有效性；
  - 去除 LPCE 后性能大幅下降（ETTh1 从 0.422 升至 0.710），说明结构化构建相位校正轨迹的重要性；
  - DPIA 优于线性投影和标准注意力两种替代，验证了基于时间上下文的增量检索的有效性；
  - SO(2) 旋转优于频率域、FiLM 和 Shear 三种替代变换，说明保范数旋转更适合相位校正。
- 超参数敏感性：$\ell=24$ 是最优窗口长度；1–2 层 MLP 预测器足够，支持"相位校正使模式更规则，轻量预测器即可"的核心假设。
- 效率方面：POEM 每样本推理时间 0.201–0.441ms，比 SRSNet 快约 2.5–4.3 倍，接近 PMDformer。
- PCA 可视化显示旋转后特征轨迹更平滑、更连贯，定性支持了相位校正的效果。

### 7. 优点

- **问题定义清晰**：形式化了"周期漂移"的概念，将其建模为非均匀相位推进（相位速度漂移 + 相位偏移），为后续方法提供了理论框架。
- **几何视角新颖**：将 $\mathrm{SO}(2)$ 旋转引入时间序列预测的相位校正，利用其可逆性和保范数性质，在特征空间实现显式的相位规范化。
- **方法设计优雅且模块化**：五个模块职责明确——LPCE 构建历史相位轨迹、SO(2) 旋转校正特征、轻量 MLP 预测、DPIA 外推未来相位、逆旋转恢复相位变化，各组件可独立替换和验证。
- **DPIA 设计有洞见**：使用**相位增量**而非绝对相位作为注意力值，避免了相位原点选择的影响；使用归一化时间戳编码的余弦相似度来匹配历史上下文，并通过可学习缩放因子控制注意力锐度。
- **轻量高效**：预测器仅需 1–2 层 MLP，推理时间低至亚毫秒级，验证了相位校正简化后续任务的核心假设。
- **实验验证完整**：主实验、消融、替代变换、超参数敏感性、效率和可视化多维验证，不仅有定量指标还有定性分析。

### 8. 不足与局限

- **训练时长未明确**：论文未报告各数据集的具体训练时间或总 GPU 小时数，削弱了计算成本评估的完整性。

- **部分数据集表现不占优**：在 US Birth 上不如简单的 DLinear（MSE 0.301 vs 0.233），在 ZafNoo 上不如 PMDformer，说明方法对某些数据特性（可能缺乏明显周期性）敏感。

- **假设限制**：方法依赖于"存在主导周期 $l_p$"和"相位扰动较小"的隐含假设，对于非周期或强非平稳序列可能失效。

- **与固定周期假设方法的对比公平性**：部分基线（如 CycleNet）需要预先指定周期长度，POEM 使用数据集级预定义主导周期，两者在周期性先验的利用方式上不对称，可能引入不公平比较的风险。
