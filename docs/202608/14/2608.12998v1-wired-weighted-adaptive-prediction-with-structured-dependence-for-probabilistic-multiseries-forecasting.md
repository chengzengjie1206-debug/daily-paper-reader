## 摘要
本文介绍了WIRED，一个用于多个相关时间序列联合概率预测的R包算法。WIRED结合了简单边际预测分布库、基于CRPS的自适应混合权重，以及用于跨序列模拟的高斯或学生t copula。我们在一个基准测试中评估了该实现，该基准包含四个合成数据生成过程（DGP）、三个预测视界、每个DGP-视界对30个重复、九个消融实验和外部基线，以及在内置EuStockMarkets数据上的滚动起源研究。核心贡献在于架构和诊断方面。WIRED将自适应边际专家聚合与依赖重构分离；基准测试支持显式依赖建模，但表明当前CRPS外推的softmax加权尚不够稳健，无法胜过简单的bootstrap或等权重替代方案。因此，本文确定了设计中的一个有效层、边际聚合层中的一个瓶颈，以及一条构建更正则化概率集成组合的具体研究路径。

## Abstract
This paper presents WIRED, an R package algorithm for joint probabilistic forecasting of multiple related time series. WIRED combines a library of simple marginal predictive distributions, CRPS-based adaptive mixture weights, and a Gaussian or Student t copula for cross-series simulation. We evaluate the implementation in a benchmark with four synthetic data-generating processes (DGPs), three forecast horizons, 30 replicates per DGP-horizon pair, nine ablations and external baselines, and a rolling-origin study on the built-in EuStockMarkets data. The central contribution is architectural and diagnostic. WIRED separates adaptive marginal expert aggregation from dependence reconstruction; the benchmark supports explicit dependence modeling, but shows that the current CRPS-extrapolated softmax weighting is not yet robust enough to dominate simpler bootstrap or equal-weight alternatives. The paper therefore identifies a working layer of the design, a bottleneck in the marginal aggregation layer, and a concrete research path for more regularized probabilistic ensemble construction.

- **核心问题**：在规划、金融、供应链、容量管理等场景中，用户需要的不仅是对每个时间序列的点预测或边际分布，而是**多个相关未来量的联合分布**。这要求同时刻画边际不确定性与跨序列依赖（如同时压力事件、尾部联动）。
- **现有方法的不足**：很多复杂联合预测模型缺乏模块化诊断，难以判断误差来自边际聚合层还是依赖建模层；同时，简单预测器的组合往往比单一复杂模型更稳健。
- **论文目标**：提出并实现一个R包算法 WIRED（Weighted Adaptive Prediction with Structured Dependence），通过分离“边际专家聚合”和“依赖重构”来提供可解释、可诊断的联合概率预测，并用基准测试定位瓶颈层。
- **整体含义**：论文的核心贡献是**架构性、诊断性**的——它验证了依赖建模层的有效性，同时指出当前自适应边际权重规则是薄弱环节，为后续更正则化的概率集成研究提供了方向。

## 2. 论文提出的方法论（核心思想、关键技术细节、公式或算法流程）

- **总体流程**：  
  `y1:T → {xt+h,j} → {Fj,h} → Ch → {X(m)} → {y~(m)}`
  即：原始水平数据 → 变换为水平对齐的移动量 → 拟合边际专家分布 → 自适应加权混合 → 估计 copula 依赖 → 生成联合情景 → 逆变换回水平尺度。
- **边际变换**：根据模式对每个序列和视界 h 定义未来移动量：  
  - 加法：`x_{t+h,j} = y_{t+h,j} − y_{t,j}`  
  - 乘法：`y_{t+h,j} / y_{t,j} − 1`  
  - 对数乘法：`log(y_{t+h,j} / y_{t,j})`
- **边际专家库**：每个序列和视界拟合 8 种简单预测分布，包括：
  - 朴素 PERT；
  - 自动 ARIMA；
  - 指数加权移动平均高斯；
  - 历史 bootstrap；
  - 漂移加残差 bootstrap；
  - 波动率缩放朴素高斯；
  - 稳健中位数/MAD（Laplace 或 Gaussian）；
  - 收缩分位数回归。
- **CRPS 自适应加权**：
  - 用样本估计 CRPS：  
    `CRPS(X,z) = (1/m) Σ|Xi−z| − (1/(2m²)) ΣΣ|Xi−Xk|`
  - 通过 expanding-window 回测得到近期的 CRPS 序列；
  - 用 Theil-Sen 斜率外推下一窗口分数，得到预测分数 ŝ；
  - 用温度缩放 softmax 转换为权重：  
    `w_k = exp(−ŝ_k/τ) / Σ exp(−ŝ_ℓ/τ)`
  - 该权重也可解释为熵正则化线性损失问题的最小化解，其中 τ 为数据自适应温度（默认取预测分数的经验标准差）。
  - 最终边际分布为：`F_j(x) = Σ w_k F_jk(x)`，分位数通过单调数值求逆获得。
- **结构化依赖（copula）**：
  - 从历史对齐移动矩阵估计相关矩阵，支持 Pearson、Kendall、Spearman 等映射到椭圆相关性：
    - Kendall：`sin(πτ/2)`
    - Spearman：`2 sin(πρ_S/6)`
  - 提供四种相关自适应模式：
    - static（静态整体相关）
    - rolling（滚动窗口）
    - EWMA（指数衰减）
    - regime（基于平滑压力分数混合 calm/stress 相关矩阵）
  - 对相关矩阵进行收缩（向单位矩阵）和特征值修复；
  - 使用 Gaussian 或 Student t copula 生成均匀分量，再通过边际分位数函数映射：`X_j = Q_j(U_j)`，最终得到联合情景。

## 3. 实验设计（数据集、场景、benchmark、对比方法）

- **合成基准**：
  - 4 个合成数据生成过程（DGP）：
    1. `regime heavy tail`（马尔可夫压力态 + 重尾）
    2. `static gaussian`（静态高斯相关）
    3. `break correlation`（相关结构断点）
    4. `independent series`（独立序列，t_7 扰动）
  - 每个 DGP：p=4 个序列，240 个训练样本，3 个预测视界（1、3、6），每个 DGP-视界组合 30 个重复。
- **真实数据**：
  - R 内置 `EuStockMarkets` 数据（DAX、SMI、CAC、FTSE 日频指数）；
  - 8 个滚动起源，预测视界 1、5、20。
- **对比变体（9 种）**：
  1. `WIRED-full`：完整自适应 CRPS 权重 + regime 依赖 + Student t copula；
  2. `No tail copula`：高斯 copula 替代 t copula；
  3. `Static dependence`：静态相关替代 regime 自适应；
  4. `Rolling dependence`：滚动相关替代 regime 自适应；
  5. `Independent marginals`：相同 WIRED 边际但独立采样；
  6. `Equal weights`：相同依赖层但边际等权重混合；
  7. `ARIMA independent`：独立 ARIMA 边际；
  8. `Bootstrap independent`：独立历史 bootstrap 边际；
  9. `Gaussian copula bootstrap`：历史 bootstrap 边际 + 静态高斯 copula。
- **评分规则**：
  - 平均边际 CRPS；
  - 多元能量分数（energy score，样本估计）；
  - 变差分数（variogram score，r=0.5）；
  - 80% 区间覆盖率和平均 80% 区间宽度。
  - 所有分数越低越好（覆盖率与宽度联合解释）。

- **充分性与公平性**：

  - 不足：只有 4 个 DGP 家族、固定 p=4、固定 240 训练长度；真实数据集单一；CRPS 外推权重受短窗口噪声影响；基准结果中 WIRED-full 不是最优，暴露出算法短板，但实验设计本身能支持主要诊断结论。

## 6. 论文的主要结论与发现

- **依赖建模层有效**：将 WIRED 的 copula 层替换为独立采样后，变差分数显著恶化（合成平均恶化约 0.00186），说明跨序列依赖重构对联合预测至关重要。
- **边际聚合层是瓶颈**：当前基于 CRPS 外推 + softmax 的自适应权重并不稳定，在多个基准中不如简单等权重甚至不如历史 bootstrap 边际。
- **最强基线**：`Gaussian copula bootstrap`（历史 bootstrap 边际 + 静态高斯 copula）在合成和真实数据中平均分最低，说明当历史移动分布足够逼近未来分布时，简单方法反而更难被击败。
- **没有收敛到单一专家**：自适应混合权重保持在多个专家之间分散（如 PERT/ARIMA/EWMA 等均有 0.11–0.13 左右权重），说明算法有实际多样性，但权重转化的“技能预测”质量不足。
- **建设性结论**：WIRED 是可扩展的包设计；下一阶段改进应聚焦于：更好的专家技能预测、权重正则化（如向等权重或 bootstrap 先验收缩）、显式引入 Gaussian-copula bootstrap 作为基线或回退模式，以及更广泛的实证验证。
