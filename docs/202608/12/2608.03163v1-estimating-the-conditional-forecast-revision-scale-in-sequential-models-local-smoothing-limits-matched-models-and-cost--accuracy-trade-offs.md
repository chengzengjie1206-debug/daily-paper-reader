## 摘要
条件预测修正尺度 $\It=\{\Var(\E[X_{t+1}\mid\F_t]\mid\F_{t-1})\}^{1/2}$ 度量了由观测 $X_t$ 引起的预测更新的历史特定大小。由于它是由两个未知条件均值构造的条件二阶矩，因此无法直接观测。我们研究了在不同结构假设和计算预算下应使用哪种 $\It$ 估计量。比较包括块自助法、条件方差模型、拟合的状态空间模型、两种 $O(1)$ 流式平滑器，以及已训练循环网络的遗忘门。误差分解将一步预测误差与条件二阶矩跟踪误差分开。我们表明，当 $\It$ 在采样尺度上变化时，外部调参的仅滞后平滑器可能不一致，尽管它们在缓慢变化下能达到通常的 $T^{-2/3}$ 均方误差率（对于 $\It$ 为 $T^{-1/3}$）；正确设定的状态空间估计器通过使用当前状态避免了这一限制。在波动率驱动的设计中，一个廉价的条件方差模型作为点估计器比已实现的块自助法更准确且便宜一百多倍，后者的价值在于其提供的抽样分布而非点跟踪。在状态驱动的设计中，只有结构匹配的滤波器才能捕获快速变化。直接读取时，已训练网络的遗忘门不跟踪 $\It$ ——尽管对完整门向量进行有监督线性探针可以做到，因此 $\It$ 是线性可解码的，但不是免费可得的。这些结果给出了一个实用规则：识别条件二阶矩结构，将估计器与之匹配，然后选择成本最低的足够方法。

## Abstract
The \emph{conditional forecast-revision scale}   $\It=\{\Var(\E[X_{t+1}\mid\F_t]\mid\F_{t-1})\}^{1/2}$ measures the   history-specific size of the forecast update induced by observing $X_t$.   Because it is a conditional second moment built from two unknown conditional   means, it is not directly observed. We study which estimator of $\It$ should   be used under different structural assumptions and computational budgets. The   comparison includes a block bootstrap, a conditional-variance model, a fitted   state-space model, two $O(1)$ streaming smoothers, and the forget gate of an   already-trained recurrent network. An error decomposition separates   one-step-prediction error from conditional-second-moment tracking error. We   show that externally tuned lag-only smoothers can be inconsistent when $\It$   changes at the sampling scale, although they attain the usual $T^{-2/3}$   mean-squared-error rate ($T^{-1/3}$ for $\It$) under slow variation; a correctly   specified state-space estimator escapes   this limit by using the current state. In volatility-driven designs, a cheap   conditional-variance model is more accurate and over one hundred times cheaper   \emph{as a point estimator} than the implemented block bootstrap, whose value   lies in the sampling distribution it provides rather than in point tracking. In state-driven designs,   only the structurally matched filter recovers the fast variation. Read directly, a   trained network's forget gate does not track $\It$ --- though a supervised linear   probe on the full gate vector does, so $\It$ is linearly decodable but not   available for free. These results yield a practical rule: identify   the conditional-second-moment structure, match the estimator to it, and then   choose the least costly adequate method.
