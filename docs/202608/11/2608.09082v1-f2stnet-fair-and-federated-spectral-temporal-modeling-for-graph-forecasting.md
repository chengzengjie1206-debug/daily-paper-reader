## 摘要
图结构数据上的时空预测是交通预测和环境监测的核心问题，然而分散且异构的数据使得序列建模和协作训练都变得复杂。我们提出了F²STNet，一种联邦预测框架，结合了截断图傅里叶特征、轻量级对角状态空间时序编码器、图卷积以及公平感知联邦聚合（FFA）。谱分支揭示图频率结构，状态空间层以序列长度的线性复杂度建模长时间依赖关系。FFA利用客户端验证损失和递增的公平性调度来调整FedAvg先验。在PeMS04、HZMetro和KnowAir上的实验显示，相对于评估的基线，预测精度更优；在PeMS04上的联邦实验还进一步改善了最差客户端和客户端离散度指标。

## Abstract
Spatiotemporal prediction on graph-structured data is central to traffic forecasting and environmental monitoring, yet decentralized and heterogeneous data complicate both sequence modeling and collaborative training. We propose F$^2$STNet, a federated forecasting framework that combines truncated graph-Fourier features, a lightweight diagonal state-space temporal encoder, graph convolution, and Fairness-aware Federated Aggregation (FFA). The spectral branch exposes graph-frequency structure, while the state-space layer models long temporal dependencies with linear complexity in the sequence length. FFA adjusts the FedAvg prior using client validation losses and an increasing fairness schedule. Experiments on PeMS04, HZMetro, and KnowAir show favorable forecasting accuracy relative to the evaluated baselines; federated experiments on PeMS04 additionally improve worst-client and client-dispersion metrics.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：图结构时空预测（如交通流量、空气质量监测）需要同时建模节点间的空间依赖与序列间的时间动态，图神经网络（GNN）是常用手段。然而，现有方法大多依赖中心化数据访问，且常用循环或注意力模块计算开销高，难以适配隐私敏感、资源受限的联邦场景。
- **核心问题**：在联邦学习（FL）框架下，数据分布在多个客户端，存在两大挑战：
  1. **统计异构性**：客户端数据分布差异大，导致全局模型泛化差、产生偏差；
  2. **公平性缺失**：FedAvg 按样本量加权，忽视客户端难度差异，导致表现较差的客户端被进一步边缘化。
- **整体含义**：论文提出 **F²STNet**，将谱域特征提取、轻量状态空间时序建模与公平感知联邦聚合统一到一个框架中，旨在实现**精确、高效且更公平**的联邦图预测，填补了“频率编码 + 轻量时间建模 + 公平聚合”综合方案在联邦时空预测中的空白。

## 2. 方法论的提出：核心思想、关键技术细节与算法流程

### 2.1 整体架构

F²STNet 由三大模块组成：
1. **谱投影模块（Spectral Projection）**
2. **线性状态空间时序模块（State-Space Temporal Module）**
3. **公平感知联邦聚合（Fairness-aware Federated Aggregation, FFA）**

### 2.2 谱投影模块

- 基于共享拓扑预先计算归一化拉普拉斯矩阵的特征分解：  
  \(\tilde{L} = U\Lambda U^\top\)，保留前 \(F\) 个特征向量，构成截断图傅里叶基 \(U_F \in \mathbb{R}^{N \times F}\)。
- 输入信号 \(X\) 通过投影得到每个节点的图频率贡献：  
  \(S_{b,t,n,f} = (U_F)_{n,f} c_{b,t,f}\)，其中 \(c_{b,t,f}\) 是图傅里叶系数。
- 用共享 MLP（两层线性 + GELU）将节点级图频率向量映射为 \(d_s\) 维嵌入，再与原始输入拼接后线性投影为时序编码器的输入。
- 该谱分支显式暴露图的高/低频结构，同时截断基仅保留主要模式，降低计算与参数量。

### 2.3 状态空间时序建模

- 采用**对角线性状态空间层**（类似 Mamba 的轻量变体）建模长时间依赖，计算复杂度为序列长度 \(T\) 的线性级。
- 状态更新过程（零阶保持离散化）：
  - \(\bar{A}_{b,t,n} = \exp(\Delta_{b,t,n} \odot A)\)
  - \(\bar{B}_{b,t,n} = (\bar{A}_{b,t,n} - 1) \oslash A \odot B_{b,t,n}\)
  - \(h_{b,t,n} = \bar{A}_{b,t,n} \odot h_{b,t-1,n} + \bar{B}_{b,t,n} \odot z_{b,t,n}\)
  - \(o_{b,t,n} = C_{b,t,n}^\top h_{b,t,n} + D \odot z_{b,t,n}\)
- 其中 \(A\) 取负值保证稳定，\(\Delta>0\) 由 softplus 产生，整个扫描在单节点序列上串行执行，但可并行处理批量与节点。

### 2.4 空间建模与预测

- 使用一层图卷积聚合时间嵌入的空间信息：
  \(H_{\text{spatial}} = \sigma(\tilde{D}^{-1/2} \tilde{A} \tilde{D}^{-1/2} H_{\text{temp}} W_{\text{gcn}})\)。
- 通过线性输出层生成未来 \(H\) 步预测，优化目标为 MSE 损失。

### 2.5 公平感知联邦聚合（FFA）

- **核心思想**：在 FedAvg 先验（按样本量加权）基础上，根据客户端验证损失的相对偏差动态调整权重，实现“性能公平性”。
- 具体流程：
  1. 客户端在本地训练后，在本地验证集上计算损失 \(L_t^k\)；
  2. 计算相对损失偏差：\(r_t^k = (L_t^k - \bar{L}_t) / \max(\bar{L}_t, \epsilon)\)；
  3. 公平加权系数：\(q_t^k = p_t^k (1 + \lambda_t r_t^k)\)，其中 \(p_t^k\) 为 FedAvg 权重；
  4. 归一化后用于聚合全局模型：\(\Theta_{t+1} = \sum_k w_t^k \Theta_{t+1}^k\)。
- 这样 **验证损失高于平均的客户端获得更多权重**，较低者权重略降，从而改善弱势客户端。
- 采用**逆退火（reverse-annealing）调度**：  
  \(\lambda_t = \min(\lambda_{\max}, \lambda_{\text{init}} + \eta t)\)，训练前期 \(\lambda\) 小，保证收敛；后期逐渐增大公平性权重，兼顾精度与公平。

## 6. 主要结论与发现

- **中心化预测**：F²STNet 在 PeMS04 和 KnowAir 上全面优于所有基线（RMSE、MAE、MAPE均为最低），在 HZMetro 上 MAE 最低，RMSE 接近最优。
- **联邦预测**：在 PeMS04 上，F²STNet 在 \(\alpha_{\text{het}}=5\) 和 \(10\) 下均取得最低 RMSE/MAE/MAPE，并显著提升公平性：
  - 复合效用-公平增益 \(\Delta = 14.166\)（远高于 FGGP 的 11.369）；
  - Max-RMSE \(30.40\)、Std-RMSE \(0.75\)，均为所有方法中最低；
- **公平性分析**：
  - 逆退火调度较固定 \(\lambda\) 和无公平性方案能更有效降低最差客户端 MAE；
  - F²STNet 的客户端 MAE 方差持续低于 FedAvg、FedProx、FGGP 等；
  - 客户端数量 \(K=10\) 时在收敛速度、效用与公平性之间取得最佳平衡。
- **效率**：以低于 1.2M 参数、5.6ms 推理延迟实现接近/优于大模型的精度，适合资源受限的边缘场景。
- **可推广性**：在 HZMetro 和 KnowAir 上联邦实验同样获得最优或接近最优结果，但 KnowAir 中因客户端多样性有限和噪声较大，优势缩小。

## 7. 优点

- **方法综合性强**：将图傅里叶谱投影、线性状态空间、（图卷积）空间建模和公平聚合整合为一个统一框架，解决以往方案碎片化的问题。
- **效率与效果兼顾**：频谱基可离线预计算，状态空间层为线性复杂度，参数量极小（<1.2M），适合带宽和内存受限的联邦设置。
- **公平性设计合理**：基于验证损失而非训练损失，避免对过拟合的直接奖励；逆退火调度兼顾收敛稳定性和公平性。
- **实验设计较全面**：三个真实数据集、多种基线、消融、超参敏感性、客户端数量分析、公平性曲线与可视化一应俱全。
- **结果呈现规范**：对 F²STNet 报告 3 个种子的均值和标准差，使用相同种子列表进行配对比较，有助于公平对比。

## 8. 不足与局限

- **实验覆盖不均衡**：主文联邦实验只展示 PeMS04，另两个数据集的联邦结果在附录；KnowAir 上优势较微弱，论文也承认噪声和低客户端多样性限制了方法的代表性。
- **消融设计不够完整**：未单独验证图卷积层的贡献，也未对比谱投影使用不同保留频率数 \(F\) 的敏感性（仅说明使用 \(F=16\)）。
- **公平性定义单一**：只考虑性能公平性（client-level performance parity），未涉及人口统计属性层面的群体公平；\(\lambda\) 的线性调整机制较为简单，论文自述未来需纳入非线性或历史依赖的权重机制。

- **资源信息不足**：缺少训练总时长、GPU 使用量、通信轮次总数和批大小设置等细节，复现成本不透明。
- **评估指标局限**：未讨论预测区间、分布外鲁棒性、对抗性联邦攻击等，适用范围偏向离线评估。
