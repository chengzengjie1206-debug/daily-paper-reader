## 摘要
来自异构物联网传感器的大规模多变量时间序列需要准确的长期预测，以用于资源调度和预测性维护。虽然最近的时间序列基础模型表现出很强的泛化能力，但它们依赖于静态参数化知识，并在推理过程中缺乏对外部历史模式的动态访问。检索增强生成（RAG）提供了一种潜在的补救措施，但其在时间序列预测中的应用受到异构来源之间幅度变化以及历史相似性与未来一致性不匹配的挑战。我们提出了CrossRAG，一种检索增强的预测框架，它集成了形状感知记忆（SAM）与RevIN归一化以进行幅度稳健的形状级检索，未来一致对比（FCC）学习以区分信息丰富的参考与具有相似历史但未来不同的难负样本，以及交叉注意力时间融合（CATF）以在表示级别将检索到的历史-未来参考对融合到骨干网络的表示中。在七个公开基准上的实验表明，CrossRAG始终优于仅参数化的基线和现有的检索增强预测方法。

## Abstract
Large-scale multivariate time series from heterogeneous IoT sensors demand accurate long-term forecasting for resource scheduling and predictive maintenance. While recent time series foundation models exhibit strong generalization, they rely on static parametric knowledge and lack dynamic access to external historical patterns during inference. Retrieval-Augmented Generation (RAG) offers a potential remedy, yet its application to time series forecasting is challenged by magnitude variations across heterogeneous sources and the mismatch between historical similarity and future consistency. We propose CrossRAG, a retrieval-augmented forecasting framework that integrates Shape-Aware Memory (SAM) with RevIN normalization for magnitude-robust shape-level retrieval, Future-Consistent Contrastive (FCC) learning to distinguish informative references from hard negatives with similar history but divergent futures, and Cross-Attention Temporal Fusion (CATF) to fuse retrieved historical--future reference pairs into the backbone's representations at the representation level. Experiments on seven public benchmarks show that CrossRAG consistently outperforms both parametric-only baselines and existing retrieval-augmented forecasting methods.

## 一、论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：多变量时间序列预测（MTSF）在生产调度、交通管理、气象预测等实际应用中至关重要。Transformer 架构在 NLP、视觉领域取得巨大成功后，被广泛引入时间序列预测，出现了 PatchTST、iTransformer、TimerXL 等代表性模型。然而，现有方法在处理变量间依赖关系和外部协变量方面存在明显短板。
- **核心问题**：
  1. **变量间依赖建模不足**：现有模型要么采用 channel-independent 策略（如 PatchTST）忽略变量间交互，要么采用 channel-mixing 策略（如 iTransformer）丢失细粒度时间动态；即使是混合方案（如 TimerXL），也假设变量对之间具有静态且均匀的相关性，无法刻画真实场景中稀疏且随时间演化的依赖结构。
  2. **噪声相关性的干扰**：在多变量系统中，许多变量间相关性是虚假的或噪声性的，不加区分地建模反而损害预测精度，需要模型具备选择性识别有意义依赖的能力。
  3. **协变量利用不充分**：日历特征、节假日指示、外部事件等协变量蕴含丰富的先验信息，但主流方法仅通过简单拼接或将协变量作为额外通道处理，忽略了异质协变量的结构差异，容易引入噪声。TiDE、ChronosX 虽尝试改进，但前者为纯 MLP 架构、后者面向单变量 token 场景，均不适用于多变量 patch 建模。
- **整体含义**：本文提出一个统一框架 TFGformer，将时频域图结构学习与协变量感知表示融合相结合，旨在同时解决动态变量依赖建模和协变量高效利用两大挑战，提升多变量长期预测的准确性和可解释性。

## 二、论文提出的方法论

### 2.1 总体架构

TFGformer 由三个核心组件构成：**Time-Frequency Graph（TFG）模块**、**Covariate Fusion Module（CFM）模块**和**Transformer 序列建模模块**。给定历史观测序列 X ∈ R^{L×C}、历史协变量 C_{history} 和未来协变量 C_{future}，模型生成预测 Ŷ ∈ R^{S×C}。

### 2.2 Time-Frequency Graph（TFG）模块

- **时频特征提取**：对每个变量 x_c 计算短时傅里叶变换（STFT）得到幅度谱图：
  - Mc = |STFT(x_c, n_fft, hop, win)| ∈ R^{F×T}
  - Z = Flatten(Mc) ∈ R^{B×C×N_{feat}}
  - 相比全局傅里叶变换，STFT 能够同时保留时间局部性和频率信息，捕捉非平稳、时变的相关结构。
- **可学习马氏距离度量**：采用可学习的马氏距离评估变量间的相似性：
  - D_{i,j} = (Z_i − Z_j)^T Q (Z_i − Z_j)
  - 其中 Q 为可学习的对称半正定（PSD）矩阵，能够捕捉时频特征空间的协方差结构。
- **概率化与稀疏化**：
  - 将距离通过倒数映射转换为相似度并屏蔽对角线：P̃_{i,j} = 1/(D_{i,j} + ε)，若 i≠j；否则为 0。
  - 通过最大值归一化获得概率矩阵 P ∈ [0,1]^{B×C×C}。
  - 将 P 视为伯努利分布的参数，通过 **Gumbel–Softmax 重参数化**采样得到离散二值掩码 G，该掩码可过滤噪声和弱相关，同时支持梯度传播。
- **注意力掩码构造**：将通道级掩码 G 与因果时间掩码 M_time 做 **Kronecker 积**：
  - M_attention = G ⊗ M_time
  - 最终掩码在注意力 softmax 之前以加性方式应用。
- **计算复杂度**：频率特征提取为 O(C·L log L)，图结构学习通过可学习的对角权重向量和 tensor broadcasting 降低至 O(C²·L)。

### 2.3 Covariate Fusion Module（CFM）

- **输入协变量融合（I-CFM）**：将历史协变量投影后与输入 patch 嵌入拼接，经 ReLU 激活和 MLP 变换后，通过残差连接加回原始嵌入：
  - Z_in = X_emb + FFN(ReLU([W_x X; W_c C_{his}]))
- **输出协变量融合（O-CFM）**：将未来协变量投影后与 Transformer 隐状态拼接，经 ReLU 和 MLP 变换后，加回投影的隐状态：
  - Z_out = W_h H + FFN(ReLU([W_h H; W_f C_{fut}]))
- **缺失值处理**：对连续协变量采用前向填充，对分类协变量采用零填充，保证融合稳定性。

### 2.4 Transformer 主干

- 采用多头上自注意力，将 TFG 模块生成的掩码在 softmax 前应用（待加性掩码），公式为：
  - Scores = (Q·K^T/√d_k) ⊙ M + (1 − M) ⊙ (−∞)
  - Out = Softmax(Scores)·V

## 六、论文的主要结论与发现

1. **TFGformer 在 6/7 个数据集上取得最优平均 MSE 和 MAE**（ETTh2、ETTm1、ETTm2、Weather、Electricity、Traffic），在 ETTh1 上也保持高度竞争力。
2. **显著优于强基线**：在所有数据集上的平均 MSE 相比 iTransformer 降低 3.6%，相比 PatchTST 降低 6.4%，相比 TiDE 降低 5.2%，相比 FEDformer 降低 16.4%。
3. **模块贡献量化**：去除 CFM 导致平均 MSE 增加 3.0%，去除 TFG 导致 MSE 增加 6.0%——表明 TFG 模块的贡献更大，两者都不可或缺。
4. **可解释性验证**：热力图显示 TFG 模块成功赋予高相关变量对更高的关系概率，同时将噪声连接概率推至零附近，实现了稀疏、可解释的依赖结构。
5. **温度参数的重要性**：τ=0.5 为最优值；过低导致图过度稀疏、丢失有效依赖，过高则重新引入噪声，说明平衡的稀疏图是必要的。

## 七、优点

1. **方法创新性强**：首次将 STFT 时频分析与可学习马氏距离结合用于图结构学习，能够捕捉非平稳、时变的变量依赖关系，超越传统全局频域方法。
2. **可解释性良好**：通过概率矩阵和热力图可视化，能直观展示模型学到的变量间依赖结构，而不仅仅是黑盒预测。
3. **噪声抑制机制巧妙**：Gumbel–Softmax 采样产生稀疏二值图，有效过滤弱相关和噪声连接，同时支持端到端梯度传播。
4. **协变量融合考虑周全**：分别设计 I-CFM 和 O-CFM 处理历史与未来协变量，通过残差连接保持原有数据特性，并考虑到了缺失值的鲁棒处理。
5. **计算复杂度可控**：通过 tensor broadcasting 和图掩码的 Kronecker 积设计，在不显著增加开销的前提下实现跨变量建模。
6. **实验覆盖较全面**：跨能源、交通、气象三个领域、28 组主实验，且消融实验验证了关键模块的必要性。
