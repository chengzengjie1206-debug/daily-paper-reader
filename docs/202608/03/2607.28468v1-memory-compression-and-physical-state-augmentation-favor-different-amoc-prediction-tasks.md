## 摘要
大西洋经向翻转环流通过简化指数进行监测和模拟，但此类预测丢弃了温盐结构，可能需要显式的物理状态或观测指数的记忆。我们在来自八个模型家族的30条分支一致的CMIP6轨迹上，使用留一族交叉验证比较了这些策略。盐度、温度和密度信息改善了直接的20年预测，而紧凑的标量记忆在每个递归时间范围中排名最高，并产生最低的案例平均布里尔评分。一项匹配的消融实验证实，记忆的反馈改善了长期预测。物理状态和近期趋势也能预测超出排放路径的未来海洋状态变化，在五年时最为稳健。NorESM在SSP5-8.5情景下揭示了标量压缩的强迫依赖限制，而MIROC显示出负的长期迁移。一种预解分析解释了为何稳定的记忆组件并不能保证完整学习模型的稳定性。因此，物理增强和记忆压缩服务于不同的AMOC预测任务。

## Abstract
The Atlantic Meridional Overturning Circulation is monitored and emulated through reduced indices, but such projections discard thermohaline structure and may require either explicit physical state or memory of the observed index. We compare these strategies in 30 branch-consistent CMIP6 trajectories from eight model families using leave-one-family-out validation. Salinity, temperature and density information improves direct 20-year forecasts, whereas compact scalar memory is top-ranked at every recursive horizon and yields the lowest case-averaged Brier score. A matched ablation confirms that feedback from memory improves long-horizon prediction. Physical state and recent trends also predict future ocean-state changes beyond the emissions pathway, most robustly at five years. NorESM under SSP5--8.5 identifies a forcing-dependent limit of scalar compression, while MIROC shows negative long-horizon transfer. A resolvent analysis explains why stable memory components do not guarantee stability of the complete learned model. Physical augmentation and memory compression therefore serve different AMOC prediction tasks.

### 2. 方法论

- **核心理论框架——Mori–Zwanzig（MZ）约化**：
  - 通过消除未解析坐标，得到瞬时解析趋势、历史依赖反馈和正交动力学三部分。
  - 该形式主义为延迟和非马尔可夫闭合提供了理论合理性，而非仅凭启发式引入滞后项。
- **矩阵Schur–Resolvent准则**：
  - 对采样提升状态（包含解析坐标 q 和隐藏记忆 z），其线性化雅可比矩阵为分块矩阵 J = [[A, B], [C, D]]，其中隐藏块稳定（rad(D) < 1）。
  - 消去隐藏状态后得到矩阵滞后核 K_k = BD^(k−1)C。
  - 论文给出 **定理1（Schur–Resolvent准则）**：det(ζI − J) = det(ζI_m − D) · det Φ(ζ)，其中 Φ(ζ) = ζI_d − A − B(ζI_m − D)⁻¹C。
  - 由此推导出**精确的恢复平衡条件**：det(I_d − A − N₀) = 0，其中 N₀ 为积分记忆反馈。该式说明瞬时解析块 A 被记忆反馈 N₀ 重新归一化，两者不可孤立解释。
- **核心思想**：
  - 投影并未移除未解析的反馈，而是将其移入记忆核；
  - 稳定的隐藏极点只保证记忆实现本身不发散，**不保证完整学习算子的收缩性**。
- **预测模型架构**：
  - 标量MZ：仅使用标量AMOC指数和历史记忆；
  - 向量滞后（vector lag）与向量MZ：显式使用物理状态（盐度、温度、密度对比）；
  - 递归传播算子使用饱和激活函数（tanh）防止轨迹发散。

### 6. 主要结论与发现

- **核心双向发现**：
  - **物理状态增强改善20年直接预测**：显式温盐信息包含标量指数缺失的长期信息，向量滞后（RMSE 1.297）与向量MZ（1.300）几乎并列；
  - **标量记忆在递归预测中全时域排名第一**：标量MZ在1、5、10、20年均最优，其20年均等家族RMSE为1.381。
- **匹配消融证实记忆反馈机制**：有反馈模型在20年MSE上8个家族中7个占优，平均配对差−2.280，精确检验p=0.03125。
- **强制依赖的压缩极限**：
  - NorESM在SSP5–8.5下向量滞后从首个时域就优于标量MZ，20年MSE优势达4.70，表明强强迫漂移下物理历史信息不可完全压缩为标量记忆；
  - MIROC显示物理状态增强在长期可能产生负迁移（−0.69技能）。
- **概率准确性**：标量MZ的Brier分数最低（20年0.1441），但向量模型保留了更强的事件排序区分能力（更高ROC-AUC）。
- **物理状态超越排放路径的信息**：条件转移技能在5年时最稳健（p_Holm=0.03125，8个家族全为正），在SSP5–8.5下最强。
- **稳定记忆组件不保证完整映射收缩性**：标量MZ本地Schur稳定率为64.0%，显著高于符号实数和振荡MZ（3.5%和4.4%），说明可学习不稳定的完整映射而产生有限但有界的预测误差。

### 7. 优点与亮点

- **任务区分是核心亮点**：明确区分固定时域直接预测与递归传播预测，并证明两种任务偏向不同的状态表示，这在AMOC预测文献中具有方法论创新性。
- **严格的跨模型家族验证**：留一族验证比轨迹内插更严苛，更真实地反映跨模型结构的迁移能力。
- **理论框架坚实**：以Mori–Zwanzig约化理论为基础，提供了记忆核的动力学解释，而非仅凭启发式引入滞后。
- **精确的消融设计**：匹配消融仅移除反馈路径而保持隐藏坐标和极点不变，精确区分"记忆容量"与"记忆反馈机制"的贡献。
- **概率评估全面**：Brier评分、ROC-AUC、可靠性分解等多角度评估超越简单点估计，且仔细处理种子平均。

- **理论透视**：Schur–Resolvent分析将记忆反馈与完整映射稳定性联系起来，对早期预警语言有方法论意义上的提醒。

### 8. 不足与局限

- **统计功效有限**：8个模型家族虽提供严格结构验证，但家族级推断功效不足——标量MZ优于向量滞后在8家族中6个占优，但精确双侧检验p=0.3125未达显著。
- **模型族间依赖性**：不同模型家族共享组件，其有效独立性低于表面上的8个单位。
- **情景覆盖不完整**：FGOALS仅贡献SSP5–8.5，场景均值需平衡家族敏感性分析。
- **物理变量覆盖有限**：仅使用表层盐度、温度和密度对比，未包含淡水输运、深层海洋热含量、风驱路径或南大洋控制变量。
- **首达时间阈值为模型相对**：70%历史均值的事件定义不构成对现实世界AMOC崩溃概率的估计。
- **观测约束与重建的张力未解决**：该研究只处理简化表示如何跨气候模型转移，不对观测上的AMOC是否减弱进行仲裁。
- **NorESM异常的解释为探索性证据**：强制依赖的物理技能与向量滞后优势的关联在家族间并非系统性，未通过所有多重比较校正。
- **计算细节不透明**：未披露具体训练硬件和时间，可复现性在模型训练层面受限。
