## 摘要
准确建模跨变量依赖关系仍然是多元时间序列预测中的关键挑战，尤其是在存在强周期性模式的情况下。许多现有方法依赖于基于注意力的机制，这些机制具有二次复杂度，并随着变量数量的增加而扩展性差。最近的无注意力聚合模型通过线性复杂度的基于核心的交互解决了这个问题，但它们没有显式利用数据中存在的全局周期结构。为了克服这一局限，我们提出了CARNet，一种循环条件核心聚合与重分配框架，通过多头核心聚合将全局循环周期信息整合到高效的基于核心的交互建模中。在多个真实世界多元预测基准上的大量实验表明，CARNet在保持跨变量依赖关系的线性复杂度建模的同时，在不同预测时间范围上持续优于强变换器基线和非注意力基线。

## Abstract
Accurately modeling cross-variate dependencies remains a key challenge in multivariate time series forecasting, particularly in the presence of strong periodic patterns. Many existing approaches rely on attention-based mechanisms that incur quadratic complexity and scale poorly with increasing numbers of variates. Recent attention-free aggregation models address this issue through linear-complexity core-based interactions, but they do not explicitly leverage the global periodic structure present in the data. To overcome this limitation, we propose CARNet, a Cycle-Conditioned Core Aggregation and Redistribution framework that integrates global recurrent cycle information into efficient core based interaction modeling via Multihead Core Aggregation. Extensive experiments on multiple real-world multivariate forecasting benchmarks demonstrate that CARNet consistently outperforms strong transformer and non-attention baselines across diverse prediction horizons while preserving linear-complexity modeling of cross-variate dependencies.

## 1. 核心问题与整体含义（研究动机和背景）
多元时间序列预测（MTSF）的核心挑战之一是准确建模变量间的依赖关系（跨变量依赖）。现有方法主要分为两类：
- **基于注意力机制的方法**（如iTransformer）虽能捕捉跨变量交互，但复杂度为二次（O(C²)），随变量数增加扩展性差。
- **无注意力聚合模型**（如SOFTS）通过线性复杂度的核心交互（core-based interactions）解决了扩展性问题，但未能显式利用数据中存在的**全局周期性结构**（如每日、每周的季节性模式）。

先前工作（如CycleNet）通过残差周期预测（RCF）学习周期并去除，但主要关注时间周期性，未建模跨变量依赖。TQNet引入周期作为全局相关性表示并通过交叉注意力建模交互，但仍依赖注意力机制。**CARNet**旨在将周期性信息高效地融入无注意力、线性复杂度的高阶聚合框架中，实现周期感知的跨变量依赖建模。

## 2. 方法论
### 核心思想
提出一个**循环条件核心聚合与重分配**（Cycle-Conditioned Core Aggregation and Redistribution）框架，将可学习的递归周期（recurrent cycle）作为全局条件信号，融入基于核心的交互建模。通过**多头核心聚合（Multihead Core Aggregation, MHCA）**将变量表示划分为多个交互子空间，提取紧凑的子空间核心表示并组合，随后通过池化得到全局核心，再结合周期投影重分配到各变量嵌入。

### 关键技术细节
1. **可学习周期表示**：使用通过自相关分析（ACF）估计的最大稳定周期长度W，初始化一个周期矩阵Q∈R^{C×W}，与输入序列相位对齐得到Z∈R^{C×T}。
2. **循环条件核心聚合**：
   - 将原始输入映射为变量嵌入X'∈R^{C×d}，周期投影为Z'∈R^{C×d}，拼接后经线性投影+GELU得到循环条件变量嵌入V'∈R^{C×d}。
   - MHCA将V'分h个头，每个头经一维卷积提取头级核心，重塑后线性混合为统一多核心表示θ∈R^{C×d'}，再经随机池化（stochastic pooling）得到共享核心θ_P∈R^{d'}。
3. **循环条件核心重分配**：
   - 将变量嵌入X'、周期投影Z'和广播后的核心θ'拼接，经两层MLP融合得到精炼表示G∈R^{C×d}。
   - 通过残差连接（X'+G）后接前馈网络（FFN），最终线性投影到预测长度H。
4. **损失函数**：均方误差（MSE）。
5. **归一化**：实例归一化（Instance Normalization），按通道归一化-去归一化。
6. **复杂度**：O(C T d + C d² + C d d' + C (d')² + C d d_ff)，对变量数C和序列长度T均为线性。

## 6. 主要结论与发现
1. **CARNet优于现有SOTA**：在12个基准上的38/48个MSE设置中取得最佳，尤其在强周期性、高维数据集（如Electricity、PEMS）上优势明显。
2. **周期信息的关键作用**：将可学习递归周期以条件信号形式集成到核心聚合与重分配中能显著提升预测精度；去掉循环条件重分配（CCCR）导致最大性能下降。
3. **多头核心聚合的有效性**：相比单核心聚合，MHCA通过多个交互子空间提取更丰富的跨变量依赖。
4. **线性复杂度，效率可接受**：虽然参数量略高于TQNet，但远低于iTransformer等，且在实际训练速度上与SOFTS相当。
5. **对周期长度选择更鲁棒**：相比TQNet，CARNet在偏离最优周期长度时性能下降更小，能利用和谐周期。
6. **收敛更快**：在10个epoch训练下仍优于许多强基线（表4），表明周期条件提供了强归纳偏置。

## 7. 优点
- **创新性地融合周期与核心聚合**：首次将全局周期结构显式引入无注意力聚合架构，拓展了SOFTS范式。
- **多头核心聚合（MHCA）**：通过划分多个交互子空间提取多样化核心表示，提高了表达能力。
- **保持线性复杂度**：与注意力方法相比可扩展到多变量场景。
- **全面且公平的实验**：覆盖12个数据集、10种基线、多种消融、固定训练预算、随机种子验证，结论可信。
- **鲁棒性分析充分**：对周期长度、回看窗口、随机种子等进行了敏感性测试。

## 8. 不足与局限
- **周期长度全局固定**：与CycleNet、TQNet一样，W通过ACF在数据集级别确定，不能自适应每个样本，对弱周期、非平稳数据效果可能下降。
- **依赖变量相关性**：作为通道依赖模型，在变量间相关性弱的数据集上优势可能缩小。
- **超参数敏感性**：性能仍依赖于隐藏维度、层数等架构选择，虽然进行了网格搜索但未给出全局最优解。
- **未考虑缺失值和异常值**：所有实验假设数据完整，实际应用中可能需要预处理。
- **缺少长序列对比**：实验仅使用回看窗口T=96，未测试更长序列（如512、720）下与其他长序列模型（如FEDformer、TimesNet）的对比。
