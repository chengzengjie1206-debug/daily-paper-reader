## 摘要
我们提出了一种可解释的低秩状态空间模型，用于逐日区域温度场的条件模拟。核心统计问题是：经验正交函数（EOF）是否可以被视为场的稳定大尺度特征，而不仅仅是用于降维的依赖于样本的基向量。该框架通过少量保留的EOF系数表示主导温度场，对其季节均值和方差结构进行建模，利用稳定的多元动力学传播所得的低维状态，并使用结构化创新来表示剩余不确定性。所得降秩模型具有可解释性、计算高效，适用于迭代集合生成。它旨在支持对保留温度状态结构的推断以及通过多时间尺度概率场模拟进行预测。

## Abstract
We propose an interpretable low-rank state-space model for conditional simulation of daily regional temperature fields. The central statistical question is whether empirical orthogonal functions (EOFs) can be treated as stable large-scale features of the field rather than only as sample-dependent basis vectors for dimension reduction. The framework represents the dominant temperature field through a small number of retained EOF coefficients, models their seasonal mean and variance structure, propagates the resulting low-dimensional state with stable multivariate dynamics, and uses structured innovations to represent the remaining uncertainty. The resulting reduced-rank model is interpretable, computationally efficient, and suitable for iterative ensemble generation. It is designed to support both inference on the structure of the retained temperature state and prediction through multi-horizon probabilistic field simulation.

### 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：经验正交函数（EOF）能否被视为区域温度场的**稳定大尺度特征**，而不仅仅是样本依赖的降维基向量？传统EOF降维方法在滚动重估时稳定性差，且缺乏物理可解释性。
- **研究动机**：在气候服务、能源规划、农业、健康风险等领域，需要跨空间和时间一致的概率温度场模拟。现有随机天气发生器难以扩展到高维网格场，且多数方法忽视低维状态的动态稳定性和可解释性。
- **整体含义**：构建一个**可解释的低秩状态空间模型**，将保留的EOF系数作为有物理意义的低维状态，进行季节调整、动态传播和结构化创新建模，实现多时间尺度（1天至120天）的概率场模拟，并揭示模拟质量随预报提前时间的依赖关系。

### 2. 方法论
- **核心思想**：将每日网格温度场投影到训练数据估计的EOF子空间，保留前K个系数（实验中K*=4）作为低维状态；对该状态进行系数依赖的季节均值和方差建模；用正则化向量自回归（VARX）传播标准化状态；最后用结构化创新模型表示剩余不确定性。此外，引入**轨迹级混合**机制：短预报提前期使用纯动态模型，长预报提前期随机分支到状态匹配的气候态延续。
- **关键技术细节**：
  - **EOF表示**：基于训练数据计算协方差矩阵的特征分解，保留前4个EOF（解释方差约96.7%-97.5%）。采用等网格权重，目标为重建的秩K*场。
  - **确定性结构**：对每个保留系数分别建模均值和方差，均值包括季节性谐波、可选的缓慢漂移项和低频气候指数（CO₂、ENSO、AMO）；方差为对数线性形式，同样包含季节性谐波和协变量。
  - **依赖模型**：标准化后的系数使用**季节特定的岭正则化VARX**模型，滞后阶数通过BIC选择，正则化使低方差模态获得更强收缩。动态稳定性通过约束伴随矩阵谱半径<0.97确保。
  - **创新模型**：分为三个层次：
    - **M1**：恒定协方差，标量色散校准，学生t冲击。
    - **M2**：基于EWMA的边际波动率，季节特异性互相关，分量色散校准。
    - **M3**：在M2基础上增加GRU校正的波动率，并与EWMA几何平均（混合权重0.5），同时使用短期通胀（前3步）。
  - **轨迹级混合**：每个集合成员在随机分支提前期Bm后切换到状态匹配的历史延续。分支概率随提前期指数衰减，参数τ从训练数据中估计。切换时使用偏移衰减和线性斜坡以保证平滑过渡。
- **算法流程**：训练 → EOF分解 → 系数均值/方差拟合 → VARX拟合 → 创新参数估计 → 模拟时生成系数路径 → 重建网格场。

### 3. 实验设计
- **数据集与场景**：使用ERA5再分析资料的地表2米日平均温度，覆盖1940-2025年。选择美国**五个气候差异显著的区域**（64×64网格）：上中西部、南加州、墨西哥湾-中南部、中部落基山、东北走廊。每个区域固定网格。
- **基准（Benchmark）**：**CLIM**（条件气候态）：从训练记录中按日历窗口采样连续多日块，保留时间依赖结构。
- **对比方法**：
  - 三个纯动态模型：**M1**（恒定协方差）、**M2**（EWMA波动率）、**M3**（GRU+EWMA混合波动率）。
  - 三个对应的混合模型：**Hybrid-M1、Hybrid-M2、Hybrid-M3**（相同动态模型+轨迹分支）。
  - 共计7个模型在5个区域、4个滚动折叠下比较。
- **验证指标**：能量分数（ES）、变异函数分数（VS）、90%经验覆盖率、暖尾超阈值面积分数CRPS（W95）、持续比（Persistence ratio）、系数空间自相关等。

### 4. 资源与算力
- 论文明确提到：**单个区域和折叠的完整流程约需15-25分钟**，使用配备**单块NVIDIA A100 GPU**和32核CPU的工作站。GRU波动率训练约占40%耗时；由于模型在K*=4维系数空间运行，峰值内存低于8 GB。整个实验（5区域×4折叠×7模型）可在**单个多GPU节点上一夜完成**。

### 5. 实验数量与充分性
- **实验数量**：5个区域 × 4个滚动折叠（测试期重叠），每个模型在每个折叠下对比8个预报提前期（1,3,7,14,30,60,90,120天）。共约7模型 × 5区域 × 4折叠 ≈ 140个组合实验，每个组合含多个预报原点（约90天步长加抖动）。此外还有消融式诊断（如自相关、PIT、季节性分析）。
- **充分性与公平性**：
  - 严格使用**滚动原点设计**，训练和测试严格分离，每个折叠内所有模型使用相同训练数据。
  - 比较基准**CLIM**为合理的非动态基线。
  - 进行了**配对原点块自举区间**估计混合增益的统计显著性。
  - 提供了丰富的结构诊断（子空间稳定性、残差白噪声、系数校准）来支撑可解释性主张。
  - 但测试期重叠导致跨折叠不能视为独立样本，作者对此有说明并仅作为稳健性总结。
- **结论**：实验设计系统、指标全面，覆盖多个维度和水平，统计可靠性较好。

### 6. 主要结论与发现
- **保留的EOF状态具有可解释性和稳定性**：前4个EOF解释96.7%-97.5%方差，子空间在滚动重估下稳定，EOF1为域尺度热模态，EOF2-4为区域对比模态。系数的季节均值、方差、漂移、尾部分布均有清晰气候含义。
- **短预报提前期动力模型收益显著**：1步预报能量分数从CLIM的52.9降至约33.4（降低约37%），依赖观测初始状态。
- **中长期（30-120天）混合模型优于纯动力模型**：混合模型在所有三个动力基础上均改善了能量分数和变异函数分数，且通过原点块自举验证显著。混合模型在90-120天表现出最佳持续比（<1.0）。
- **无单一模型在所有指标上胜出**：M3/Hyb-M3在能量分数和覆盖上略好，但M1/M2更保守。CLIM在暖尾诊断（W95）上仍保持竞争力，因为它直接重采样历史极值。
- **区域异质性显著**：海湾-中南部尾部最重，南加州混合时间尺度最长，中部落基山和海湾-中南部需要更长的VARX滞后。

### 7. 优点
- **可解释性强**：EOF系数被赋予物理意义（区域热模、对比模），季节结构和低频协变量关联可直接解读。
- **计算高效**：只操作4维状态空间，避免全网格数据物化，训练和模拟速度快、内存要求低。
- **结构灵活**：创新模型分层次（常数→EWMA→GRU），可根据诊断自动选择复杂度；混合机制自适应调整预报提前期。
- **验证严谨**：使用多指标（ES、VS、W95、覆盖、自相关）和统计自举推断，结论可靠。
- **滚动原点的严格设计**避免了过拟合，且强调了时间序列验证的难度（测试期重叠的恰当处理）。

### 8. 不足与局限
- **仅针对秩K*=4重建场**：未建模秩外变异，因此不能直接用于局地微气候或站点级极端风险评估，需要额外降尺度或随机残差空间分量。
- **低频协变量处理**：CO₂、ENSO、AMO在历史记录中部分时段缺失（填充），且与漂移项共线性，不能做因果解释。ONI在90-120天预报期间可能变化，固定协变量假设变弱。
- **气候态基准（CLIM）没有趋势调整**：历史非平稳性导致CLIM略有欠覆盖，混合模型在长提前期接近该欠覆盖，建议未来增加趋势调整的气候态基准。
- **混合参数选择为开发阶段固定值**：除τ外（从数据估计），其他分支参数（hmin, R, δ, ntop, T）为固定设计选择，未进行敏感度分析。
- **实验仅覆盖美国五个区域，气候多样性有限**：结论是否推广到其他大陆或海洋区域未知。
- **多变量扩展缺失**：当前仅模拟温度，未来可联合模拟降水、风速等变量。
