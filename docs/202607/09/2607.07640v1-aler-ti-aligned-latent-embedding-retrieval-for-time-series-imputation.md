## 摘要
深度学习显著推进了时间序列插补，然而大多数现有架构主要依赖于受损输入序列中的局部时间上下文。在现实场景中，这种依赖可能具有局限性，因为时间序列常常表现出非平稳动态、弱时间相关性以及难以仅从邻近观测中重建的罕见模式。在本文中，我们提出了ALER-TI，即对齐潜在嵌入检索用于时间序列插补，这是一种检索增强框架，明确利用历史模式来补充退化的局部上下文，以实现更可靠的缺失值重建。ALER-TI的核心是潜在嵌入对齐（LEA），它减轻了受损查询与完整历史候选之间的表示不匹配。通过在潜在空间中应用事后掩码，LEA将候选与查询的缺失模式对齐，同时允许历史嵌入被预先计算并缓存以实现高效检索。ALER-TI是模型无关的，可以通过轻量级适配模块与各种插补骨干集成。在六个真实世界数据集上、不同缺失率下的广泛实验表明，ALER-TI consistently 改善了强基线模型，并增强了在多样插补设置中的鲁棒性。

## Abstract
Deep learning has significantly advanced time series imputation, yet most existing architectures primarily rely on localized temporal context within the corrupted input sequence. This reliance can be limiting in real-world scenarios, where time series often exhibit non-stationary dynamics, weak temporal correlations, and infrequent patterns that are difficult to reconstruct from nearby observations alone. In this paper, we propose ALER-TI, Aligned Latent Embedding Retrieval for Time Series Imputation, a retrieval-augmented framework that explicitly leverages historical patterns to supplement degraded local context for more reliable missing-value reconstruction. The core of ALER-TI is Latent Embedding Alignment (LEA), which mitigates the representation mismatch between corrupted queries and complete historical candidates. By applying post-hoc masking in the latent space, LEA aligns candidates with the query's missingness pattern while allowing historical embeddings to be pre-computed and cached for efficient retrieval. ALER-TI is model-agnostic and can be integrated with various imputation backbones through a lightweight adaptation module. Extensive experiments on six real-world datasets under different missing rates demonstrate that ALER-TI consistently improves strong baseline models and enhances robustness across diverse imputation settings.

## 一、核心问题与整体含义（研究动机和背景）

- **问题背景**：现有深度学习时间序列插补方法（如 CNN、Transformer、分解网络）主要依赖**局部时间上下文**（即当前输入序列中观测到的相邻时间点）来重建缺失值。
- **局限**：真实世界时间序列常呈现**非平稳动态**、**弱时间相关性**、**罕见模式**，仅靠局部观测难以重建。例如，当缺失段对应罕见事件或附近观测信息不足时，模型表现显著下降。
- **解决思路**：借鉴检索增强范式（在时间序列预测中已成功），通过检索历史相似模式来补充局部上下文，为缺失值重建提供显式参考。
- **核心挑战**：插补任务中查询序列本身是**不完整的（缺失值扭曲表示）**，与完整历史候选之间存在**表示不匹配**。简单检索（如独立编码查询和候选）会导致相似度衡量失效；而动态掩码重新编码所有候选则计算开销巨大。

## 二、提出的方法论

### 核心思想
ALER-TI 是一个**模型无关**的检索增强框架，核心组件为**潜在嵌入对齐（LEA）**。LEA 采用**掩码无关编码 + 后验潜在对齐**策略：
- 历史候选独立编码并**离线缓存**，避免在线重新编码。
- 查询编码时通过**候选引导的注意力机制**与缓存候选进行交互，实现表示对齐且保持高效。

### 关键技术细节

1. **候选编码**  
   - 使用 Transformer 编码器 `fθ` 对完整历史候选 `pi` 进行编码，**不应用查询掩码**。  
   - 输出 `zci = fθ(pi)` 预计算并缓存。

2. **查询编码（候选引导）**  
   - 从观测 token 中提取多个上下文视图：引入 `m` 个可学习查询码 `qr`，通过注意力聚合观测 token 隐表示 `hj` 得到上下文向量 `zqr`。  
   - 再利用候选表示 `zci` 作为引导，对上下文向量加权得到查询最终表示 `zqi`。  
   - 相似度计算：`si = zqi^T * zci`。

3. **后验掩码**  
   - 在潜在层统一应用查询缺失模式，实现对齐同时保留离线缓存优势。

4. **对比训练**  
   - **正样本构造**：对真实值做季节-趋势分解（STL），取确定性成分（趋势+季节）作为正参考。  
   - **硬负挖掘**：基于 Pearson 相关系数选取高相关但非正样本的候选作为负样本。  
   - **损失函数**：InfoNCE 对比损失（式 10）。

5. **检索增强插补**  
   - 检索到 top-k 候选后，通过**轻量适配器**融合骨干模型输出：门控机制 `g = σ(MLP_g(z_bb))` 动态融合，再经残差 MLP 细化。  
   - 最终输出保留观测值，仅替换缺失部分（式 2）。  
   - 训练目标仅优化缺失部分 MSE（式 16），骨干冻结。

### 算法流程简述
1. 训练阶段：构建候选池 → 训练 LEA（对比损失）→ 冻结骨干 → 训练适配器（MSE损失）。  
2. 推理阶段：预计算候选嵌入 → 编码查询 → 潜在空间相似度匹配 → 检索 top-k → 适配器融合 → 输出插补结果。
