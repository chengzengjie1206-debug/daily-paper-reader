## 摘要
不规则多变量时间序列在医疗监测、人类活动识别和环境感知等应用中广泛存在。其核心挑战源于异步观测、非均匀采样间隔，以及时间模式本身携带关键动态信息这一事实。现有方法要么依赖基于离散化的预处理（如插值、填补或聚合），这破坏了底层的连续时间语义；要么采用基于ODE框架的连续时间建模，这通常需要专门的架构，并且由于数值求解器而带来大量计算开销。为解决这些局限性，我们提出了WrapFlow，一种用于不规则时间序列预测的连续时间建模框架。在输入侧，WrapFlow引入了连续时间令牌化，直接编码原始观测事件，并通过间隙感知令牌显式建模长未观测区间。生成的连续时间令牌随后由标准Transformer主干处理，以捕获长程时间依赖性。在输出侧，我们开发了一种免模拟的训练范式用于残差流匹配，该范式在基础预测周围学习条件残差向量场，同时避免训练过程中的数值求解器模拟和反向传播。这种设计使得仅需在推理时使用少量固定 rollout 步骤即可实现高质量的连续预测。在多个真实世界数据集上的大量实验表明，WrapFlow实现了最先进的性能。

## Abstract
Irregular multivariate time series are widely encountered in applications such as healthcare monitoring, human activity recognition, and environmental sensing. Their core challenges stem from asynchronous observations, non-uniform sampling intervals, and the fact that temporal patterns themselves carry critical dynamic information. Existing approaches either rely on discretization-based preprocessing (e.g., interpolation, imputation, or aggregation), which disrupts the underlying continuous-time semantics, or adopt continuous-time modeling via ODE-based frameworks, which typically require specialized architectures and incur substantial computational overhead due to numerical solvers. To address these limitations, we propose WrapFlow, a continuous-time modeling framework for irregular time series forecasting. On the input side, WrapFlow introduces Continuous-Time Tokenization, which directly encodes raw observation events and explicitly models long unobserved intervals via gap-aware tokens. The resulting continuous-time tokens are then processed by a standard Transformer backbone to capture long-range temporal dependencies. On the output side, we develop a simulation-free training paradigm for Residual Flow Matching, which learns conditional residual vector fields around base predictions while avoiding numerical-solver simulation and backpropagation during training. This design enables high-quality continuous forecasting using only a small number of fixed rollout steps at inference. Extensive experiments on multiple real-world datasets demonstrate that WrapFlow achieves state-of-the-art performance.

- 现有方法存在两类主要局限：
  - **离散化预处理方法**（插值、填补、聚合等）将不规则数据对齐到固定时间网格，虽然实现简单，但会破坏原始的连续时间语义，造成不可逆的信息扭曲。
  - **基于 ODE 的连续时间方法**（如 Neural ODE 等）虽然理论上更合理，但通常需要专用架构和数值求解器，导致训练/推理计算开销大，优化复杂。

## 2. 提出的方法论：核心思想、关键技术细节与流程

WrapFlow 是一个统一的连续时间建模框架，包含**输入侧表示建模**和**输出侧连续生成**两大互补模块，中间用标准 Transformer 主干连接。

### 核心思想
- 输入侧：提出连续时间令牌化（Continuous-Time Tokenization），将每个原始观测事件编码为带时间语义的令牌，直接保留连续时间信息，避免离散化。
- 输出侧：提出免模拟训练的残差流匹配（Residual Flow Matching），在“基础预测”周围学习条件残差向量场，训练时不需要数值求解器模拟和反向传播，推理时只需少量固定步 Euler rollout。

### 关键技术细节

1. **连续时间令牌化**：设计了三种令牌类型，分别对应不同语义状态：
   - **事件令牌（Event Token）**：编码观测值、变量嵌入、绝对时间、相对时间间隔和事件类型嵌入，公式为  
     \( z_{nk} = g_v(x_{nk}) + e_{var}^n + \phi_{abs}(t_{nk}) + \phi_{rel}(\Delta t_{nk}) + e_{\text{event type}} \)
   - **间隙感知事件令牌（GAP-aware Event Token）**：当同一变量距离上一可见事件的时间超过阈值 \(\tau_{gap}\) 时，在普通事件令牌上叠加 GAP 类型嵌入，显式建模长未观测间隔所携带的信息。
   - **掩码间隙令牌（Mask GAP Token）**：训练时随机掩码一段连续历史，用不含观测值但保留变量身份和时间信息的令牌表示，并作为自监督恢复目标。
2. **Transformer 主干**：按变量将令牌序列输入共享的掩码注意力 Transformer，得到历史上下文记忆 \(M\)。
3. **基于查询的解码器**：构造值无关的未来查询和掩码历史查询，通过交叉注意力从对应变量的历史记忆中检索上下文，得到条件上下文 \(c\) 和基础预测/重建（如 \(\bar{x}_{nf,j} = \text{MLP}([c_{nf,j} \| \psi(s_{nj})])\)）。
4. **残差流匹配**：
   - 未来分支：将最终预测拆分为基础估计 + 残差，即 \(y = \bar{x} + r\)，训练时在随机噪声和目标残差之间做线性插值，学习条件速度场 \(v_\theta(x_\tau, \tau, t, c, \bar{x})\)。
   - 掩码历史分支：对训练时掩码的历史位置施加类似的自监督流匹配损失，增强残差向量场对不规则历史上下文的利用。
   - 训练损失为 \(L = L_{dir} + \lambda_f L_f + \lambda_h L_h\)，其中 \(L_{dir}\) 是基础估计的直接预测损失，\(L_f\) 和 \(L_h\) 分别是未来分支和掩码历史分支的速度匹配损失。
5. **推理流程**：从零残差状态 \(r_0=0\) 出发，沿学习到的向量场做轻量 Euler 积分（\(\tau\in[0,1]\)），最终将终点残差 \(r_1\) 加到基础预测上，获得最终预测。
