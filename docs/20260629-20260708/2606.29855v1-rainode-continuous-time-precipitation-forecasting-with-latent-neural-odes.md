## 摘要
在降水预报中，不仅准确性至关重要，时间分辨率也极为关键。然而，提高时间分辨率受到观测限制以及密集离散模型计算成本的制约。为克服这一限制，我们将降水预报重新表述为一个连续时间动力系统，并提出RainODE框架，该框架利用神经ODE在潜在空间中建模降水演变。这一公式能够实现导数一致的时间动态，并捕捉降水系统的主要大尺度平流运动。然而，纯确定性ODE难以表示非平流的强度变化，如局部增长、衰减和亚网格变异性，常常导致预测过于平滑。为解决这一问题，我们引入了一个基于布朗桥公式的随机源建模模块，该模块在保持平流一致性的同时，细化残差强度变化并恢复精细结构。通过将确定性连续动态与随机细化相结合，RainODE能够在保持清晰预测的同时实现任意时间推断。在SEVIR和新引入的基于雷达的降水综合数据集（RAPID）上的实验表明，RainODE在多个时间间隔和降水状态下均取得了一致的改进。代码可在https://github.com/SeongYE/RainODE获取。

## Abstract
In precipitation forecasting, not only accuracy but also temporal resolution is critical. However, increasing temporal resolution is constrained by observational limitations and the computational cost of dense discrete modeling. To overcome this limitation, we reformulate precipitation forecasting as a continuous-time dynamical system and propose RainODE, a framework that models precipitation evolution in latent space using a Neural ODE. This formulation enables derivative-consistent temporal dynamics and captures the dominant large-scale advective motion of precipitation systems. Nevertheless, a purely deterministic ODE struggles to represent non-advective intensity changes such as localized growth, decay, and sub-grid variability, often leading to over-smoothed predictions. To address this issue, we introduce a stochastic source modeling module based on a Brownian Bridge formulation, which refines residual intensity variations and restores fine-grained structures while preserving advective consistency. By combining deterministic continuous dynamics with stochastic refinement, RainODE enables arbitrary-time inference while maintaining sharp predictions. Experiments on SEVIR and the newly introduced Radar-based Precipitation Integrated Dataset (RAPID) demonstrate consistent improvements across multiple temporal intervals and precipitation regimes. The code is available at https://github.com/SeongYE/RainODE.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：传统的降水预报模型大多是**离散时间**的，即在固定的时间间隔（如5分钟、1小时）上进行帧到帧的预测。这带来了两个主要问题：
    - **计算成本与时间分辨率的矛盾**：要提高预测的时间分辨率（例如从1小时间隔提升到10分钟间隔），自回归模型会产生严重的误差累积，而多对多模型的计算复杂度会急剧上升，两者都难以平衡效率和精度。
    - **物理过程的不连续性**：大气演变是连续过程，离散模型无法捕捉帧间时刻的真实动力学演化，且预测结果在时间轴上缺乏一致性（如隐式模型对不同时间点的预测是独立生成的）。
- **整体含义**：该论文旨在**重新定义降水预报的范式**，将其从离散的帧预测问题转化为一个**连续时间的动力学系统建模问题**。通过引入神经ODE，RainODE能够在潜在空间中学习降水系统大尺度平流的连续演化轨迹，从而实现在任意时间点进行预测，并保持物理动力学的一致性，突破了离散模型的限制。

### 2. 论文提出的方法论：核心思想、关键技术细节

RainODE的核心思想是**将确定性的大尺度平流运动与随机性的局部强度变化解耦并分别建模**。

- **第一阶段：基于潜在神经ODE的确定性平流动力学**
    - **连续时间重定义**：受降水物理学方程（平流+扩散+源汇）启发，将大尺度平流运动建模为连续时间动态。
    - **技术细节**：
        1.  **编码与翻译**：输入雷达序列 `X` 经2D编码器提取潜在特征 `Z`，再通过一个翻译器网络预测未来离散时刻的潜在状态 `Z_T+1`。
        2.  **潜在神经ODE**：以翻译器输出的第一个未来状态 `z(0)` 为初始条件，定义一个潜在轨迹 `z(s)` 在归一化时间 `s` 上的演化。其动态由神经ODE网络 `f_ODE` 参数化：
            `dz(s)/ds = f_ODE(z(s), z(S), s)`
            `z(s) = z(0) + ∫ from 0 to s f_ODE dτ`
        3.  **训练目标**：
            - **重建损失**：最小化翻译器直接预测的教师序列 `ˆY_teacher` 与真实值 `Y` 之间的MSE。
            - **一致性损失**：最小化经过ODE积分后解码得到的连续预测序列 `ˆY_ODE` 与教师序列 `ˆY_teacher` 之间的MSE，强制ODE轨迹与离散预测对齐。
            - 总损失：`L_stage_I = 重建损失 + α * 一致性损失`。

- **第二阶段：基于布朗桥的随机源建模**
    - **动机**：确定性ODE只能捕捉平流主导的运动，会产生过于平滑的预测，无法表示局地增长、衰减等非平流过程（对应物理方程中的扩散和源汇项）。
    - **技术细节**：引入一个基于**布朗桥扩散过程**的随机模块（SSM）。
        - 将ODE的确定性预测 `ˆY_ODE` 视为起点 `y_0`，将真实值 `Y` 视为终点 `y_K`。
        - 定义前向扩散过程，在起点和终点之间构建一条随机路径：
            `y_k ~ N( (1 - k/K) * y_0 + (k/K) * y_K , 2k(K-k)/K² * I )`
        - 该过程在连接预测和真值的同时，引入了精确控制的随机性，模拟了不可预测的局部变化。
    - **作用**：在保持平流一致性的前提下，恢复了高频率空间结构和局部强度变化，使得最终预测更清晰、更准确。

- **连续时间建模的有效性**：RainODE通过连续时间动力学建模，在多个数据集和时间间隔上一致性地优于所有离散基线，尤其是在长时间预测（如RAPID-60min）和高强度阈值预测（CSI-219）上表现突出。

- **潜在空间一致性**：RainODE的潜在轨迹比离散基线模型的轨迹更平滑、更连续，表明其更有效地学习到了时间上的语义演化。

- **实验设计的全面性与公平性**：

- **实际应用价值**：RainODE支持**任意时间点推断**的灵活性，对于需要高灵活性和不同时间精度的实际气象业务具有重要价值。计算效率（参数不随预测长度增长）也颇具吸引力。

### 8. 不足与局限

- **数据模态单一**：正如论文在“局限与未来工作”部分所述，当前的工作**仅限于雷达数据**。对于极长时预报（如6小时），仅靠雷达数据难以捕捉新生的、源自大尺度环流背景的天气系统，这是根本性的性能天花板。
- **实验覆盖的局限性**：
    - **缺乏在多模态数据上的验证**：未将RainODE扩展到融合卫星、数值预报产品等更多模态的数据上，而这些数据对改善长时预报至关重要。
    - **未充分讨论不确定性量化**：虽然引入了随机建模模块，但并未将其显式用于输出带置信区间的概率预报，而是作为一个生成更清晰确定值的手段。

- **计算成本**：虽然参数数量不变，但其FLOPs随着ODE求解器的积分步数增加而线性增长，在追求极高时间分辨率时，计算成本依然不低。
