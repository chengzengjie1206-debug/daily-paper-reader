## 摘要
函数型数据分析（FDA）提供了分析时间连续随机过程样本的统计方法。测量数据通常以关键科学变量的传感器数据形式出现。不规则传感器中断的实际问题促使了对部分观测随机函数进行分析的兴趣。具体而言，本文的动机来自于一个间歇性缺失的污染数据时间序列，该序列在污染路径和缺失模式上具有依赖性。为了进行统计分析，我们首次提出了适用于相依的、部分观测的函数型时间序列的推断方法。现有方法因严重依赖于数据函数的独立性而不适用于此任务。数学上，我们在定义上确界范数的有界函数空间上对数据进行建模。这使得我们能够在整个函数域上进行联合推断，包括联合置信带——这是现有基于希尔伯特空间的方法所无法提供的。为了研究时间序列上的非平稳趋势，我们将最先进的多尺度推断方法（最初为标量数据开发）扩展到部分观测函数。这些方法的关键应用是检测内城区过高的污染水平。我们的方法结合了最先进的高斯逼近和随机过程理论。有趣的是，该方法通过避免使用函数中心极限定理，还改进了针对完全观测函数型时间序列的现有结果。

## Abstract
Functional data analysis (FDA) provides statistical methods for analyzing samples of time-continuous stochastic processes. Measurements often arise in the form of sensor data for a key scientific variable. The practical problem of irregular sensor disruptions has fostered interest in analyzing partially observed random functions. Specifically, this paper is motivated by a time series of intermittently missing pollution data with dependence along pollution paths and missingness patterns. To allow statistical analysis, we develop the first inference methods for dependent, partially observed functional time series. Existing methods were not appropriate for this task, because they heavily rely on the independence of the data functions. Mathematically, we model data on the space of bounded functions equipped with the supremum norm. This allows simultaneous inference across the entire functional domain, including simultaneous confidence bands -- something existing Hilbert-space-based methods cannot provide. To study non-stationary trends along the time series, we extend state-of-the-art multiscale inference methods (originally developed for scalar data) to partially observed functions. The key application of the latter methods is testing for excessive pollution levels in inner cities. Our approach combines state-of-the-art Gaussian approximations with stochastic process theory. Interestingly, it also improves existing results for fully observed functional time series by avoiding a functional CLT.

- **核心问题**：本文旨在发展**首个适用于相依的、部分观测的函数型时间序列的推断方法**，能够处理函数观测和缺失模式均存在自相关的情况，并实现**同时推断**（如同时置信带）以及**非平稳趋势检验**（如阈值超限检测）。
- **应用动机**：城市污染监测数据（如 PM10），传感器时常中断，数据存在时间和缺失模式的双重依赖，且需要检测污染水平是否超过健康阈值。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 建模空间与数据表示
- 采用**有界函数空间 \(\ell^\infty[0,1]\)** 并赋予上确界范数，而非传统的 \(L^2\) 空间。这使得逐点评估有定义，更适合部分观测（点处观测值要么有要么无），并且可以构建同时置信带。
- 每个函数 \(X_i(t)\) 被观测到的部分由随机集合 \(O_i \subset [0,1]\) 指示，定义 \(O_i(t)=I\{t\in O_i\}\)，实际观测曲线 \(Y_i(t)=O_i(t)X_i(t)\)。
- 假设数据由物理依赖（physical dependence）结构生成，满足 (2.2) 式，即 \((ε_i(t), O_i(t)) = (G_1(t,\mathcal{F}_i), G_2(t,\mathcal{F}_i))\)，其中 \(\mathcal{F}_i\) 是独立同分布噪声的推移。这允许严格平稳性和弱依赖，同时避免了\(\ell^\infty\)中不可测性问题。

### 2.2 同时置信带（SCB）的构造
- **点估计**： \(\hat\mu(t) = \frac{1}{\hat N(t)}\sum_{i=1}^N X_i(t)O_i(t)\)，其中 \(\hat N(t)=\sum O_i(t)\)。
- **离散化极大统计量**：在 \(p\) 个网格点 \(t_j\) 上定义 \(bT_N = \sqrt{N} \max_j |\hat\mu(t_j)-\mu(t_j)|\)。
- **高斯逼近**：证明 \(bT_N\) 在高维高斯逼近下收敛至连续高斯过程 \(|W(\cdot)|_\infty\) 的分布，其中 \(W\) 的协方差为 \((\pi(t)\pi(s))^{-1}\sigma_Y(t,s)\)，\(\pi(t)=E[O_i(t)]\)，\(\sigma_Y\) 是 \(Y_i\) 的长程协方差。逼近基于 Zhang & Cheng (2018) 的高维高斯逼近理论，并放宽了条件（避免了函数CLT）。
- **插值置信带**：对每个网格点构造置信区间 \(\hat C^\pm(t_j) = \hat\mu(t_j) \pm q_{1-\alpha}N^{-1/2}\)，然后在网格间线性插值得到全函数域的带状置信区间。利用均值函数的 Hölder 连续性和高斯反集中性质证明渐近覆盖率为 \(1-\alpha\)。
- **条件**：要求网格数 \(p\sim N^{C^*}\)，且 \(C^* > 1/(2\vartheta)\)，其中 \(\vartheta\) 是均值函数的 Hölder 指数。

### 2.3 多尺度局部推断（非平稳时间序列）
- 考虑模型 \(X_i(t)=\mu_i(t)+\varepsilon_i(t)\)，其中均值可能随时间变化。
- **多尺度统计量**：
  - 对于平稳性检验（Hstat₀）：\(\widehat{M}_N(t) = \max_{1\le l<k\le N-l} \frac{U_{k-l}^{k}(t)-U_{k}^{k+l}(t)}{\hat\pi_N(t)\sqrt{l}\log_2(eN/l)}\)，其中 \(U_a^b(t)=\sum_{m=a+1}^b X_m(t)O_m(t)\)。
  - 对于阈值超限检验（H∆₀：\(\sup \nu(t,x)\le \Delta\)）：\(\widehat{R}_N(t) = \max_{1\le l<k\le N} \frac{U_l^k(t)-(k-l)\Delta\hat\pi_N(t)}{\sqrt{k-l}\log_2(eN/(k-l))}\)。
- **极限分布**：在相应的原假设下，在多项式增长网格上的最大值收敛到布朗运动 \(B_W\) 的模量连续性泛函（例如 \(\Phi(B_W), \Psi(B_W)\)），其中 \(B_W\) 是高斯过程 \(W\) 对应的布朗运动。证明需要更强的矩条件和依赖衰减假设（指数衰减）。
- **功效**：对于局部备择（如流行病变化点、渐进变形），给出了信号强度和尺度的条件，表明多尺度统计量能以接近最优的速度检测信号（短信号需幅度大，长信号可幅度小）。
